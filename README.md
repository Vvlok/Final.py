# Глобальное потепление: информационный сайт на Flask

Сайт о глобальном потеплении: причины, последствия, интересные факты, викторина и калькулятор углеродного следа.

## Возможности

- Главная с ключевыми цифрами
- Информационные страницы: причины, последствия, что делать
- Страница с вкладками «Интересное» (лёд, океан, погода, природа, города, хорошие новости)
- Викторина из 9 вопросов с разбором ответов
- Калькулятор углеродного следа

## Технологии

Python 3, Flask (Jinja2), HTML, CSS

## Структура

```
├── main.py            # маршруты и запуск
├── data.py            # тексты, факты, вопросы
├── calc.py            # расчёт углеродного следа
├── requirements.txt
├── templates/         # HTML-шаблоны
└── static/css/        # стили
```

## Запуск

```
pip install -r requirements.txt
python main.py
```

Сайт откроется по адресу http://127.0.0.1:5000

## Примечание

Цифры приблизительные и округлены. Калькулятор даёт только оценку порядка величин.
