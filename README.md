# 🌍 Глобальное потепление: информационный сайт на Flask

> Сайт о том, почему нагревается планета, чем это грозит и что можно сделать. С фактами, викториной и калькулятором личного углеродного следа.

*Автор: Локайчук Варвара*

---

## 📖 О проекте

Тема глобального потепления окружена цифрами и спорами, в которых легко запутаться. Цель проекта: собрать основное в одном месте, простым языком и без запугивания, а затем дать человеку возможность проверить себя и посчитать собственный вклад.

**Чем проект может быть полезен:**

- школьникам и студентам как краткий справочник по теме;
- тем, кто хочет быстро разобраться в причинах и последствиях без чтения длинных статей;
- тем, кому интересно, сколько CO₂ они выбрасывают и что сильнее всего влияет на результат.

---

## ✨ Функции и особенности

### 🏠 Главная
Короткое вступление и четыре ключевые цифры по теме, а также карточки-ссылки на все разделы сайта.

### 📚 Информационные страницы
Три раздела со ступенчатой навигацией (кнопка «Дальше» ведёт к следующему разделу):

| Раздел | О чём |
|---|---|
| **Причины** | откуда берётся потепление |
| **Последствия** | к чему оно приводит |
| **Что делать** | что можно изменить на уровне человека и общества |

### 🔎 Интересное
Страница с вкладками: **лёд, океан, погода, природа, города, хорошие новости**. В каждой вкладке по три карточки с фактами. Хорошие новости вынесены отдельно, чтобы сайт не оставлял только тяжёлое впечатление.

### ❓ Викторина
- 9 вопросов с выбором одного ответа;
- после проверки показывается результат (из 9) и итоговая оценка одного из трёх уровней;
- **разбор каждого ответа**: что выбрано, что верно и почему.

### 🧮 Калькулятор углеродного следа
Оценка годовых выбросов CO₂-эквивалента по шести категориям:

- автомобиль (км в неделю);
- общественный транспорт (км в неделю);
- перелёты (короткие и дальние);
- электричество (кВт·ч в месяц);
- питание (от мяса почти каждый день до растительного);
- отходы (сортируются или нет).

В результате видно:

- общий след в тоннах за год;
- сравнение со среднемировым значением (≈ 4,7 т) и с ориентиром на середину века (2 т);
- столбики по категориям, чтобы было видно, что даёт больше всего;
- сколько деревьев нужно, чтобы поглотить такой объём за год;
- **советы именно для самой «тяжёлой» категории**.

Ввод проверяется: пустые, отрицательные и некорректные значения не ломают расчёт.

### 🛠 Особенности реализации

- Все тексты, факты и вопросы вынесены в отдельный файл `data.py`, поэтому содержимое можно менять, не трогая код страниц.
- Единый базовый шаблон `base.html`: шапка и меню одинаковы на всех страницах, меню собирается автоматически из данных.
- Своя страница ошибки 404.
- Адаптивная вёрстка: сайт читается и на телефоне.
- Коэффициенты калькулятора собраны в одном месте в начале `calc.py`, их легко уточнить.

## 🚀 Установка и запуск

**Требования:** Python 3.9 или новее.

```bash
# 1. Скачай проект
git clone https://github.com/<твой-логин>/<название-репозитория>.git
cd <название-репозитория>

# 2. (по желанию) создай виртуальное окружение
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Установи зависимости
pip install -r requirements.txt

# 4. Запусти сайт
python main.py
```

После запуска сайт откроется по адресу **http://127.0.0.1:5000**.

### Структура проекта

```
├── main.py            # маршруты и запуск
├── data.py            # тексты, факты, вопросы викторины
├── calc.py            # расчёт углеродного следа
├── requirements.txt   # зависимости
├── templates/         # HTML-шаблоны (Jinja2)
│   ├── base.html
│   ├── main.html
│   ├── info.html
│   ├── facts.html
│   ├── quiz.html
│   ├── calculator.html
│   └── 404.html
└── static/css/
    └── style.css      # стили
```
